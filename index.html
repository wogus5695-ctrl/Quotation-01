KEY FEATURES

실제 사용 흐름에 맞춘 7가지 기능

첨부된 앱 사용 설명서에 나온 순서대로 핵심 기능을 정리했습니다.

01FREE

사업자 등록

사업자등록증과 통장사본을 촬영해 주요 정보를 채우고, 회사 도장도 사진으로 등록하세요.

02PRO

문자 캡처로 견적서

고객에게 받은 문자를 캡처하고 ‘신규견적서 찾기’를 누르면 연락처와 현장주소를 불러옵니다.

03FREE

견적서 만들기

고객 정보와 품목을 입력하면 금액과 합계를 자동 계산해 견적서를 작성할 수 있습니다.

04FREE · PDF 저장

발행하기

도장이 들어간 문서를 미리 확인하고 PDF로 저장하세요. 앱에서 바로 보내는 기능은 PRO입니다.

05문서 연결

다음 서류 만들기

최근 현장에서 기존 견적서 내용을 이어 계약서·거래명세서·청구서·영수증을 작성할 수 있습니다.

06PRO

도장 찍어 보내기

받은 PDF 또는 사진에 회사 도장을 원하는 위치에 놓고 전송할 수 있습니다.

07PRO

이메일·문자 바로 전송

문서를 이메일로 보내거나, 인사말과 서류 이미지를 문자로 전송할 수 있습니다.
