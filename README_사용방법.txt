모두종합환경 홈페이지 · 파일 안내
=================================

1. 시작하기
- index.html : 홈페이지 메인
- support/index.html : AI 견적 비서 고객지원
- privacy/index.html : 개인정보처리방침(검토용 초안)
- terms/index.html : 이용약관(검토용 초안)
- edit.html : 오프라인 편집용 페이지
- config.js : 회사/앱/정책의 실제 표시 내용
- styles.css : 디자인
- app.js : 표시 기능

2. 회사 정보 수정(프로그래밍 몰라도 가능)
① 압축파일을 풀고 edit.html을 브라우저로 엽니다.
② 상호, 대표자, 이메일, 앱 설명 및 정책 등의 항목을 수정합니다.
③ 'config.js 내려받기' 버튼을 누릅니다.
④ 다운로드된 config.js 파일을 압축 해제한 폴더 안의 config.js에 덮어씁니다.
⑤ index.html을 열고 수정 내용을 확인합니다.

※ 이미 호스팅 중인 사이트에 반영하려면 변경된 config.js를 다시 배포해야 합니다.
※ edit.html은 공개 웹서버에 업로드하지 마세요.

3. 공개 웹사이트에 올릴 파일
index.html, styles.css, app.js, config.js, support/폴더,
privacy/폴더, terms/폴더

5. 앱 심사 전 반드시 확인할 사항
- 실제 문의 가능한 이메일 등록 및 수신 시험
- 개인정보처리방침 실제 앱 데이터 처리 방식 반영(현재는 초안)
- 약관 실제 서비스 정책에 맞게 검토
- 연결된 링크를 모바일 및 PC에서 모두 확인
- 웹사이트 HTTPS 적용, 외부에서 로그인 없이 열림 확인
- 공개 주소는 주거지 노출 위험을 고려하여 사용자 확인 후 기재
